# AI Context — quan-ly-thu-chi

## 1. Current Architectural State

- **App version:** 1.6.0 (release tagged `v1.6.0`; Pages deploy succeeded).
- **Chat routing:** LLM-only. `aiRouter.sendMessage` no longer uses regex NL classifiers (`textDraftParser` / table parsers / spoken `tạo đơn` short-circuit). Flow: pending slot-fill → multi-line paste via `extractBulkDrafts` → `extractChatIntent` / `extractMultiChatIntents` → tools. Kind (expense vs revenue) is owned by the LLM; sanitize no longer flips kind.
- **LLM profiles:** extract/bulk/slots = Groq → Gemini → Kilo → rest; free chat (`generateChatReply`) = user cascade (Kilo Free first).

- **Dashboard:** "Sản phẩm cần làm" aggregates pending order line items (excl. completed/cancelled), sorts priority-first then by qty.
- **Revenue grid:** product column with item badges; `REVENUE_MIN_WIDTH` 1270; `TableHScroll` for horizontal scroll.
- **Orders:** priority fields + chat "ưu tiên"; LLM prompt maps `"tạo đơn hàng khách …"` → `create_revenue`.
