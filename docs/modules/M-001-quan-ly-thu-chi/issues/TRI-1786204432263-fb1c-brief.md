# BA-Lite Brief: Notification Store + Bell Panel

> **Triage:** `TRI-1786204432263-fb1c` | **Class:** C2 | **Change type:** scope_expansion
> **Module:** M-001 — Quản Lý Tài Chính

## WHAT

The bell notification icon on the top bar currently only displays sync status (synced/pending/offline) and a "Đồng bộ ngay" button — wasteful panel real estate. This feature adds:

1. **Centralized notification store** (`src/store/notificationStore.ts`) — a Zustand store holding a history of application notifications with types `sync | import | ai | realtime | error`, each carrying a title, message, timestamp, and read state. The store supports `add`, `markRead`, `markAllRead`, `clear`, and exposes an `unreadCount` selector. Max 50 entries; oldest trimmed on overflow.

2. **Wire existing service events into the store:**
   - `intakeService.ts:persistConfirmed` — after the existing `notify.success(...)` toast, push a notification of type `import` with title "Nhập dữ liệu" and the same message body.
   - `realtimeSync.ts` — after the existing `notify.message(...)` toast, push a notification of type `realtime` with title "Đồng bộ thời gian thực" and the same message body.
   - `syncEngine.ts:flushOutbox` — caller (`Layout.tsx:handleSync`) should push a notification of type `sync` on flush success (`flushed > 0`) and type `error` on flush failure (`failed > 0`).

3. **Updated Bell panel in `Layout.tsx`:**
   - **Badge** on the Bell icon: displays `unreadCount` (instead of the current `pending > 0` dot).
   - **Panel content** (replaces the current sync-only card):
     - Header: "Thông báo" + "Đánh dấu đã đọc" button (visible when `unreadCount > 0`).
     - Compact sync status bar (retained, reduced height): colored dot + text ("Đã đồng bộ" / "Đang đồng bộ..." / "Ngoại tuyến").
     - Scrollable notification list (max 8 most recent items), each showing:
       - Icon mapped by type: `RefreshCw` (sync), `FileUp` (import), `Bot` (ai), `Radio` (realtime), `AlertTriangle` (error) — all from `lucide-react`.
       - Title (bold), message body, relative timestamp ("2 phút trước", "1 giờ trước").
       - Unread items: slightly darker background.
       - Click marks as read.
     - Empty state: "Chưa có thông báo".
     - "Đồng bộ ngay" button retained when `pendingCount > 0`.

4. **Store barrel export** — add `useNotificationStore` export to `src/store/index.ts`.

## ENTRY POINT

Chuông thông báo trên top bar (Layout.tsx) - người dùng click vào icon Bell để xem panel thông báo

## ORACLE

### Build-time gates
- `bun run typecheck` — `npx tsc --noEmit` exits 0, no new TS errors.
- `bun run build` — `npx vite build` exits 0.

### Runtime acceptance
1. **Bell badge:** When the notification store has N unread entries, the Bell icon in the top bar shows a badge with the number N.
2. **Panel displays notifications:** Clicking the Bell opens the panel showing: (a) the compact sync status bar, (b) the list of most recent notifications (up to 8).
3. **Notification types show correct icon:** Each notification displays the icon matching its type per the mapping: sync→RefreshCw, import→FileUp, ai→Bot, realtime→Radio, error→AlertTriangle.
4. **Import notification:** After a CSV/OCR import succeeds (positive `ok` from `persistConfirmed`), a notification of type `import` appears in the store and panel with the import success message.
5. **Realtime notification:** When a Supabase realtime change event fires, a notification of type `realtime` appears in the store and panel.
6. **Sync notification:** When `handleSync` in Layout.tsx flushes the outbox and `flushed > 0`, a notification of type `sync` appears. When `failed > 0`, a notification of type `error` appears.
7. **Mark as read:** Clicking a notification in the panel marks it as read (background returns to normal) and decrements the badge count.
8. **Mark all read:** The "Đánh dấu đã đọc" button in the header marks all notifications as read and clears the badge.
9. **Empty state:** When no notifications exist in the store, the panel shows "Chưa có thông báo".
10. **Max 50 notifications:** Adding a 51st notification trims the oldest.
11. **Panel retains sync button:** When `pendingCount > 0`, the "Đồng bộ ngay" button is still present in the panel.
